## Sistema de control de calidad del agua

**IoT · Laravel · ESP32 · PostgreSQL/MySQL · Dashboard Web**

Sistema desarrollado como proyecto de titulación para el monitoreo del proceso de purificación de agua.

El proyecto integra un módulo IoT basado en **ESP32 y sensores** con una plataforma web para visualizar y gestionar los parámetros obtenidos durante el proceso.

<p align="left">
<img src="https://skillicons.dev/icons?i=laravel,php,arduino,postgres,mysql&theme=dark" height="32" alt="Water monitoring stack"/>
</p>

### Características

* Monitoreo de **pH, turbidez y conductividad**.
* Captura de datos mediante **ESP32 y sensores**.
* Dashboard web para visualización de mediciones.
* Gestión y seguimiento de parámetros fuera de rango.
* Generación de reportes en PDF.
* Parámetros basados en la **norma boliviana NB 512**.
* Sistema desarrollado y desplegado de forma independiente.

> Proyecto privado debido a las condiciones establecidas con la organización.
